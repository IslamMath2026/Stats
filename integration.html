Integration rules (for reference)
Power rule∫ xⁿ dx = xⁿ⁺¹/(n+1) + C , n ≠ −1
Constant multiple∫ k·f(x) dx = k ∫ f(x) dx
Sum / difference∫ (f ± g) dx = ∫ f dx ± ∫ g dx
Sine∫ sin(kx) dx = −cos(kx)/k + C
Cosine∫ cos(kx) dx = sin(kx)/k + C
Exponential∫ e^(kx) dx = e^(kx)/k + C
Reciprocal∫ 1/x dx = ln|x| + C
Inverse tangent∫ 1/(x²+a²) dx = (1/a) arctan(x/a) + C
Inverse sine∫ 1/√(a²−x²) dx = arcsin(x/a) + C
Definite integral∫ₐᵇ f dx = F(b) − F(a)
